# HR-Analytics-Dashboard-PowerBI
Interactive HR Analytics Dashboard built using Microsoft Power BI to analyze employee attrition, demographics, departments, salary, job roles, job satisfaction, age, and experience.

📊 HR Analytics Dashboard | Power BI

I’m excited to share my HR Analytics Dashboard, created using Power BI.

For this project, I started with data cleaning and preparation to make the dataset accurate and ready for analysis. After that, I used Power BI to transform the data, create calculations, and build an interactive dashboard.

🔍 What does this dashboard show?

The dashboard provides an overview of:
 👥 Total Employees & Active Employees
📉 Employee Attrition Count & Attrition Rate
🎂 Average Age
💼 Average Experience
🏢 Attrition by Department
💰 Attrition by Salary Slab
👔 Attrition by Job Role & Job Satisfaction
👨‍👩‍👧 Age Group Distribution
⚥ Attrition by Gender
📈 Attrition Trend by Experience
🏢 Department-wise Employee Count

🛠️ Tools & Skills Used
Power BI | Power Query | Data Cleaning | Data Transformation | DAX | Data Visualization | Dashboard Design

This project helped me improve my understanding of how raw HR data can be transformed into meaningful insights through data analytics and visualization.
